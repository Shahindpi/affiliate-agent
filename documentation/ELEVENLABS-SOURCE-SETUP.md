# ElevenLabs affiliate source setup

1. Create or choose the ElevenLabs brand and the relevant Dewdora affiliate products.
2. Enter your tracking URL in each product's **affiliate_url** field. Keep the official website in **website_url**; these are different values.
3. In **Affiliate Agent → Sources**, add exact official product/feature URLs as `OFFICIAL_WEBSITE`, official documentation URLs as `OFFICIAL_DOCS`, and your affiliate resource URL as another trusted source. Add their respective hostnames to allowed domains.
4. Add product assets and screen recordings in **Affiliate Agent → Media**. Add manual brand notes and prohibited/allowed claims as a MANUAL source. Verify any specific claim yourself before approving it.
5. Click **Sync Now** on every source, inspect imported text and source URL, then click **Approve factual source**. The planner uses only these approved documents. Missing facts are not supplied automatically.
6. Run one mock video through Review first; then configure real providers in the server environment for production output.

The source sync does not connect to or change an ElevenLabs affiliate program account. Affiliate tracking remains the URL that you entered on the product.
