# Affiliate sources

1. In **Admin → Brands**, create or select the real brand; in **Products**, set its official product URL and your own affiliate tracking URL. The source sync never overwrites the tracking URL.
2. Open **Affiliate Agent → Sources → Add source**. Enter the brand ID, name, source type, exact HTTPS URL, and comma-separated allowed hostnames. For `https://elevenlabs.io/`, use `elevenlabs.io`; pasting the HTTPS URL also works because it is converted to its hostname. Raw IP addresses are ignored and cannot authorize a source. Add separate sources for product pages, features, documentation and the affiliate resource page.
3. Click **Test** to verify the configured host, public DNS, HTTP response and extraction. Test records a separate timestamp/result and never changes the sync status or last sync time. Click **Sync Now** to fetch, extract and persist a pending knowledge snapshot before the card becomes `SYNCED`; the admin request completes the pipeline and refreshes the card. A failure appears as `SYNC_FAILED` with its HTTP status and error. Scheduled automatic syncs still require the `agent-sources` queue worker. Inspect run history and expand each imported document.
4. Click **Approve factual source** for verified text. Only approved documents from enabled sources feed automatic research. Import CSV using columns `title,body,source_url`, or choose MANUAL for brand notes; imported entries still require approval.
5. For WEBHOOK, set a secret in the source credentials. POST JSON `{ "title": "…", "body": "…", "source_url": "https://…" }` to `/api/v1/affiliate-agent/webhooks/{source_id}` with `X-Agent-Signature` equal to hex HMAC-SHA256 of the raw body using that secret. It creates pending documents.

Website and documentation sync fetch only the configured URL, check robots.txt, pin a public IP, reject redirects, and run at most once per configured frequency. They do not crawl arbitrary links. API sources currently perform a trusted GET with optional bearer token; use manual or CSV import for APIs requiring custom payloads or pagination. Do not approve outdated or unverifiable claims.

For example, set the ElevenLabs website source URL to `https://elevenlabs.io/text-to-speech` and allow `elevenlabs.io`. `NOT_SYNCED` and `Last sync: Never` are correct after Test alone. A completed Sync Now creates a pending source document, records a completed run and updates Last sync. Another attempt while `SYNCING` is rejected; if a worker is interrupted, a stale attempt can be retried after three minutes. CSV imports create runs as well and require at least one valid row. `Next sync` is left unscheduled for manual notes and CSV imports.
