# Review and revision

1. Open **Affiliate Agent → Review queue**, select the finished content item and preview master video, narration, script, scenes, captions, CTA, disclosure, all five platform metadata sets, QA and version history.
2. Give natural-language feedback on all content or a particular component/scene; lock any approved parts first. Example: “Shorten the intro, keep the CTA unchanged.” You can also submit a direct component edit.
3. Wait for the revision worker. It creates V2/V3… with a before/after summary and reruns only necessary voice/render steps. Review again. Restoring a historical version creates a new version.
4. Optionally save feedback as a future preference; it applies to later generated content, never unrelated existing items.
5. Click **FINAL_APPROVE** only after QA and review. Any subsequent edit or lock change invalidates approval. The publisher verifies the exact version/hash and source video assets before sending.

See `docs/affiliate-agent-review.md` for the earlier detailed review walkthrough.
